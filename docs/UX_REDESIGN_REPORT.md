# Доработка пользовательского интерфейса

Обновлена текущая дизайн-система. Изменения внесены в React и CSS. API, PostgreSQL, бизнес-переходы и проверки полномочий остались прежними.

- Очередь показывает статус и срок без боковой прокрутки на 360 px. Развёрнутые фильтры доступны по запросу. Поиск, фильтры и номер страницы восстанавливаются при возврате из карточки.
- Внутренние заметки и сообщения автору редактируются в отдельных черновиках. Под полем указан получатель. Сохранение другого действия не очищает текст, а переход к новой карточке сбрасывает предыдущие черновики.
- Общий диалог использует уникальное описание и возвращает клавиатурный фокус после закрытия. У основного индикатора фокуса увеличена толщина.
- В обзоре улучшения рядом видны владелец, количество выполненных задач, факт внедрения и заключение. Вкладка «Результат» по-прежнему показывает дельту, порог и ограничения.
