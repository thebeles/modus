# Конкурсный выпуск «Модус · Контур»

Выпуск объединяет серверные исправления из `50cfbd9` и UX-доработки. Самостоятельный демонстрационный профиль Compose использует отдельные тома, локальные порты и работает без Groq. См. [запуск и сценарий показа](DEMO_RUNBOOK.md).

- Обращение регистрируется при отсутствии подходящей очереди. Назначение восстанавливается после возврата маршрута.
- Радар разделяет наблюдения и учебные примеры. Карточка улучшения показывает динамику, достижение порога и заключение проверяющего. Ревизии заключения сохраняются. Связанная публикация отзывается при пересмотре.
- Радар получает итоги по типам и статусам из одной агрегатной выборки. Дополнительные тесты сверяют сводку с отдельными аналитическими API.
- Учебное заключение `DEMO-I-02` показывает недостаточность наблюдений. `DEMO-I-01` связывает заключение с двумя синтетическими измерениями. Повторный seed корректирует исходные демозаписи и сохраняет заключения, созданные пользователями.
- Мобильная очередь сохраняет фильтры при возврате и помещается в ширину 360 px. Заметка обработчика и сообщение автору используют независимые черновики. Диалоги восстанавливают фокус. На обзоре улучшения добавлена сводка о владельце, задачах, внедрении и результате.
- Соседние ссылки в карточке получили минимальную область нажатия 24 px. Запрос уточнения становится доступен после сохранения предыдущего действия, чтобы завершение заметки не закрывало новый диалог.
- Вошли девять миграций технических исправлений `20261112001000`–`20261112009000`. UX и конкурсная конфигурация новых миграций не добавляют. Для запуска используются Node.js 24, pnpm 11.25.0 и PostgreSQL 17.
- Prisma-схема описывает существующие правила четырёх внешних ключей и три GIN-индекса. Проверка расхождения схемы добавлена в CI. Изменение не требует новой миграции.

Данные демонстрации синтетические. Корпоративные интеграции, политика аналитических срезов, проверка с живым Groq и ClamD и промышленная эксплуатация требуют отдельной приёмки. [Границы проверенного выпуска](RELEASE_READINESS.md).
