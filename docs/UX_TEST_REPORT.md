# Проверка UX «Модус · Контур»

Проверки выполнены в Chromium на отдельном Docker Compose-стенде с новым томом PostgreSQL, миграциями и синтетическими демоданными. Проверяемая версия — рабочая ветка `codex/ux-review` от `50cfbd9`. API и worker запущены из исходной версии, frontend собран из рабочей ветки.

## Адаптивность и доступность

| Роль | Экраны | Ширина viewport, px | Горизонтальное переполнение страницы | axe-core на 1600 px |
|---|---|---|---|---|
| Сотрудник | `/`, `/appeals/new`, `/my/appeals`, `/notifications`, `/changes` | 360, 390, 768, 1024, 1280, 1600 | 0 из 30 проверок | 0 нарушений на 5 экранах |
| Обработчик | `/work-queue`, `/problems` | 360, 390, 768, 1024, 1280, 1600 | 0 из 12 | 0 на 2 экранах |
| Руководитель | `/improvements`, `/radar` | 360, 390, 768, 1024, 1280, 1600 | 0 из 12 | 0 на 2 экранах |
| Администратор | `/admin/users`, `/admin/outbox-failures` | 360, 390, 768, 1024, 1280, 1600 | 0 из 12 | 0 на 2 экранах |

Проверка ширины сравнивала `scrollWidth` документа и viewport. Вложенная таблица очереди проверена отдельно на 360 px. Её содержимое требовало 480 px при доступных 342 px в исходной версии и поместилось в 342 px после изменения. Снимки главной сотрудника на 390 px, очереди на 360 px и Радара на 1440 px приведены в [отчёте о доработках](UX_REDESIGN_REPORT.md). Административный экран дополнительно измерен на 768 px.

Для axe-core включены теги `wcag2a`, `wcag2aa`, `wcag21aa`, `wcag22aa`. Playwright проверил подачу обращения с клавиатуры на 360 px и возврат фокуса после закрытия диалога по Escape. Замеры axe относятся к исходному состоянию страниц после загрузки.

## Автоматизированные и браузерные тесты

| Проверка | Результат |
|---|---|
| `pnpm -C frontend lint` и `pnpm -C frontend typecheck` | Успешно |
| `docker build -t modus-ux-review-web:local frontend` | Успешно, предупреждения о комментариях Zod и размере основного чанка |
| Запуск Compose с миграциями | PostgreSQL, API, worker и web прошли healthcheck |
| `pnpm -C frontend test:e2e` с `UX_FIXTURES=true` | 19 из 19 за 1,5 минуты, включая все 16 исходных и 3 новых сценария |
| Очередь на 360 px | Содержимое таблицы помещается, поиск сохраняется при возврате, черновики разделены, Escape возвращает фокус |
| Передача после поиска среди более 100 обращений | Загружено 102 тестовых записи. В UI найдена самая старая цель `UX-0`. PostgreSQL вернул `TRANSFERRED\|UX-0` |
| Непрочитанное уведомление за первой страницей | Загружено 51 тестовое уведомление. Старейшее открыто из списка непрочитанных. PostgreSQL подтвердил заполнение `readAt` |

Регрессия покрыла подачу и уточнение, переназначение, отклонение с причиной, согласование и проверку эффекта, агрегаты Радара, доступ к приватному обращению, публикацию, ручную подачу при недоступном Groq и конфликты версий. Сценарии выполнялись через Chromium с реальным API и PostgreSQL. В отдельных тестах Playwright подменяет ответ для проверки пограничного состояния.

Для воспроизведения двух сценариев с длинной историей применить `frontend/tests/ux-fixtures.sql` на свежей одноразовой демобазе, указать её адрес в `E2E_BASE_URL` и запустить `pnpm -C frontend test:e2e` с `UX_FIXTURES=true`. Обычный прогон сохраняет исходные сценарии и новый тест мобильной очереди.

## Открытые проверки

- `NOT VERIFIED` — Safari, Firefox, физические мобильные устройства, скринридеры, увеличенный текст, полный клавиатурный обход и открытые состояния всех диалогов. Полное соответствие WCAG 2.2 AA требует этих проверок и ручной оценки.
- `NOT VERIFIED` — визуальная проверка каждого состояния детальных карточек и всех административных форм на каждой ширине.
- `NOT VERIFIED` — замеры производительности на объёме данных заказчика, внешний вызов Groq с действующим ключом и пользовательский пилот.
- Отдельные unit- и integration-наборы backend в этом прогоне не запускались. Сохранность бизнес-переходов подтверждена неизменённым кодом backend и перечисленными браузерными сценариями.
