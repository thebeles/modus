# План реализации

- [x] Обследование. Репозиторий содержал ТЗ и данные без исходного кода.
- [x] Инфраструктура, БД, две миграции, серверные сессии и политика доступа.
- [x] Подача, маршрутизация, обработка, уточнения и история обращений.
- [x] Проблемы, связи, улучшения и измерения.
- [x] Радар, публикации, обратная связь.
- [x] Адаптер Groq, валидация с заменяемым провайдером и ручной режим.
- [x] Документация по запуску, безопасности, эксплуатации и демо.
- [ ] Полное соответствие ТЗ. Открытые пункты зафиксированы в [трассировке](TRACEABILITY.md).

Приложение строится как модульный монолит. PostgreSQL хранит доменные записи, серверные сессии и задания worker. Веб-клиент использует API того же origin через reverse proxy.

## Проверено локально

- Установка по lockfile, lint, TypeScript и сборка приложения.
- `docker compose up --build -d --wait` завершился успешно. PostgreSQL и API прошли проверки готовности, worker и Nginx запустились. Сборка проверена в Chromium на http://localhost:5173 под профилями сотрудника и руководителя.
- 5 модульных тестов workflow, календаря, политики, загрузок и минимизации контекста AI.
- Миграции на PostgreSQL 17, двойной сид и сверка всех 20 исходных номеров, типов и приоритетов.
- 6 интеграционных проверок настоящего API и PostgreSQL. Проверены отзыв и ротация сессии, CSRF, конкурентные записи, идемпотентность, первый человеческий ответ, уточнение, пересмотр, закрытые записи и вложения, согласование и публикация, обратная связь, отказ Groq.
- 12 сценариев Playwright в Chromium. Проверены подача и очередь, уточнение, отказ, назначение, весь цикл улучшения, радар, библиотека, объектный доступ, неполная проверка, режим без Groq, конфликт версий и мобильная форма. Главная проверена на 360, 768, 1280 и 1600 px.
- PostgreSQL-дамп демонстрационной базы восстановился в отдельной базе. Запрос подтвердил 23 строки обращений. Согласованное восстановление файлового тома требует отдельной проверки.
