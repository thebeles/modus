# Подсказки Groq

Настройка на сервере: `GROQ_AI_ENABLED=true`, `GROQ_API_KEY` и `GROQ_MODEL`. Модель по умолчанию `openai/gpt-oss-20b` поддерживает структурированный JSON по документации провайдера. Доступность для вашего аккаунта проверяется при включении. [Модель](https://console.groq.com/docs/model/openai/gpt-oss-20b) · [Структурированные ответы](https://console.groq.com/docs/structured-outputs)

`AiProvider` изолирует запрос к провайдеру. API валидирует структурированные ответы через Zod и сверяет идентификаторы с разрешёнными источниками. Для всех функций требуется явное согласие. Обычный контекст минимизируется, адреса, телефоны и распознанные секреты маскируются. Конфиденциальные обращения и файлы в провайдер не отправляются.

Доступны заголовок и вопросы к черновику, похожие темы, сводка обработчика и анализ улучшения. Результат возвращается в интерфейс для проверки человеком. Логи использования хранят статус и объём, без исходного текста. При недоступности доступны ручные формы и поиск похожих обращений по совпадениям категории, процесса и слов в заголовке. Для моделей с JSON Object Mode можно настроить `GROQ_OUTPUT_MODE=json_object`. В этом режиме Zod продолжает проверять ответ. Живой запрос к Groq в автоматические тесты не входит.
