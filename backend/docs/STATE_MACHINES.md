# Состояния и решения

## Обращение

Регистрация всегда создаёт обращение. Если допустимый маршрут отсутствует, карточка ждёт назначения и доступна автору. Worker повторяет поиск маршрута и после назначения уведомляет автора и получателя. Обработчик принимает его на рассмотрение. После принятия возможны работа, запрос уточнения и закрытие с решением. При запросе сохраняется этап возврата. Ответ автора или обоснованное возобновление руководителем возвращает обращение на этот этап. Закрытие в ожидании требует основания, напоминания и выдержки срока.

Обычный отзыв требует причины. Запрос отзыва конфиденциальной записи обрабатывает специальная очередь. Автор закрытого или отозванного обращения может подать запрос на пересмотр. Решение о возобновлении сохраняется в истории. Первое видимое содержательное сообщение уполномоченного человека или решение фиксирует время первого ответа.

## Проблема

Гипотеза → исследование → подтверждение либо опровержение → закрытие. Подтверждение требует наблюдения и источника. При закрытии и возобновлении указывается основание. Подтверждённое тематическое сходство сохраняет тип связи.

## Улучшение

Черновик → согласование → согласовано → работа → внедрено → проверка → завершено. Отклонение и отмена завершают инициативу. Отложенную инициативу можно повторно подать на согласование. Для согласования нужны задачи и план проверки. Внедрение требует выполнения блокирующих задач и описания сделанного. Для завершения нужна верификация.

Для вывода об эффекте нужны наблюдения до и после внедрения. Итог «Недостаточно данных» позволяет завершить проверку при неполной выборке. Для направленной количественной проверки цель должна быть достигнута и значение должно измениться в нужную сторону относительно исходного. Для диапазона отдельно учитывается удержание в пределах границ. Завершённое заключение пересматривает назначенный независимый проверяющий. При принятии новой версии история сохраняется, прежняя публикация отзывается и может быть подготовлена заново. Обратная связь сохраняется отдельно от вывода проверяющего. Публикация проходит собственное согласование.
