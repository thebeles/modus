# Допущения и границы внедрения

- Демо-структура подразделений, маршруты, SLA и роли синтетические. Для SLA принят календарь пн–пт, 09:00–18:00 по Asia/Almaty, без праздников. Продолжительность первого ответа и следующего действия настраивается по приоритету.
- Область полномочий строится на точном подразделении, очереди и назначении. Дерево подразделений используется в справочнике. Наследование полномочий по иерархии потребует согласования с заказчиком.
- Исходные приоритеты и статусы демонстрационные. Отметки «Реализовано» не представляют подтверждённый корпоративный эффект. Публикация и измерения DEMO-I-01 используют искусственные выборки.
- Радар группирует по времени создания. Конфиденциальные записи исключены. Число источников может отличаться от общего размера базы.
- Рабочий обмен с 1С требует настройки HTTP-сервиса заказчика. Email, SSO, Битрикс24, праздники, расширенная редакционная политика и политика хранения данных требуют локальных организационных решений.
- Загрузки используют локальный закрытый том. В production доступны PNG, JPEG и TXT. PDF доступен в деморежиме. Промышленный сканер и документы Office требуют согласования.
- Сессии хранятся на сервере и действуют восемь часов. Сид отключён в production. Демонстрационный Compose предназначен для локального использования.
