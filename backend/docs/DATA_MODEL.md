# Модель данных

Источник карточки хранится в `seedOrigin` и `isSynthetic`. У комментария, события, решения, первого ответа, наблюдения и верификации свой источник. `USER_ACTION` обозначает реальное действие в приложении, включая действия с учебными карточками. `DEMO_FIXTURE` обозначает пример из seed, `IMPORTED` зарезервирован для подтверждённого импорта, `UNKNOWN` исключается из наблюдаемых KPI. В `ORIGINAL_DOCX` неизменяемы исходные поля и идентификатор, а исходные карточки остаются синтетическими.

У карточки без маршрута `queueId` равен null. Поля причины, срока повтора и числа попыток образуют сохраняемое задание worker. `AppealNextAction` хранит последовательность назначений с владельцем или очередью, сроком, состоянием и основанием ожидания. `VerificationRevision` хранит неизменяемые снимки прежних версий, а `VerificationAmendment` — основания и решения назначенного проверяющего.

| Группа | Записи и связи |
|---|---|
| Доступ | User, OrganizationUnit, Session, QueueMember. Сессия содержит хеш токена и хеш CSRF. |
| Настройки | Category, BusinessProcess, WorkQueue, RoutingRule, SlaPolicy. Резервная очередь уникальна для каждого класса доступа. |
| Обращения | Appeal с автором, очередью, подразделением, категорией и процессом. Comment, Attachment и ReviewRequest связаны внешними ключами. |
| Проблемы | Problem, ProblemAppeal, ProblemFinding. |
| Связи | AppealLink хранит каноническую пару обращений, тип и решение. Связи с проблемами и улучшениями хранятся в таблицах соединений. |
| Улучшения | Improvement, ImprovementAppeal, ApprovalDecision, ActionItem, MeasurementPlan, Measurement, Verification, Feedback. |
| Публикации | Publication с собственной редакционной версией, утверждающим и аудиторией. |
| Эксплуатация | AuditEvent, OutboxJob, Notification, Sequence, IdempotencyKey, RateBucket, AiUsage. |

UUID используется для рабочих объектов. Номера A, P и I выделяются атомарно через Sequence. В исходных A-001…A-020 snapshot хранит необработанные значения приложения Б. Нормализованные статусы отделены от исходных. «Реализовано» и «Отклонено» переносятся в закрытое обращение с итогом и явной синтетической маркировкой. Сид сохраняет уже внесённые изменения.

Версия увеличивается при изменении обращения, инициативы, проблемы, связи, публикации или ответа на приглашение. Обновления дочерних задач и измерений используют версию инициативы. Измерения после внедрения помечаются заменёнными при возврате на доработку. Снятая верификация сохраняется в истории. Поиск по подстроке поддержан индексами pg_trgm для заголовка, номера и описания.
