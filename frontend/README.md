# Frontend

- `src/` — React, маршруты, клиент API и стили.
- `tests/` и `playwright.config.ts` — сквозные сценарии в Chromium.
- `nginx.conf` — проксирование API и выдача клиентского приложения в Compose.
- [Интерфейс и скриншоты](docs/UX_SPEC.md)

Установите зависимости из `frontend/` по [инструкции запуска](../README.md#разработка-и-проверки). В этой папке `pnpm dev` читает локальный `.env` и запускает Vite, а `pnpm build` проверяет типы и собирает клиент. Прокси Vite по умолчанию обращается к API на порту 4000. Команда `pnpm test` запускает браузерные тесты против тестовой базы или запущенного демостенда. [Подготовка Playwright](../backend/docs/TEST_PLAN.md)
