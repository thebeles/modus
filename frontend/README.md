# Frontend

- `src/` — React, маршруты, клиент API и стили.
- `tests/` и `playwright.config.ts` — сквозные сценарии в Chromium.
- `nginx.conf` — проксирование API и выдача клиентского приложения в Compose.
- [Интерфейс и скриншоты](docs/UX_SPEC.md)

Установите зависимости из [корня репозитория](../README.md#локальная-разработка). В этой папке `pnpm dev` запускает Vite, а `pnpm build` проверяет типы и собирает клиент. Прокси Vite по умолчанию обращается к API на порту 4000. Браузерные тесты запускаются командой `pnpm test:e2e` с [тестовой базой](../backend/docs/TEST_PLAN.md).
